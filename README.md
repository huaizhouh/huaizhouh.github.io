# Tier Studio

纯 HTML、CSS、JavaScript 的图片分级排序工具，可直接部署到 GitHub Pages。无需构建、账号、服务端或第三方运行依赖。界面为中文，所有图片均在浏览器本地处理。

## 功能

- 多图上传、文件拖入；鼠标、触屏拖拽；同层内排序、跨层移动和多图一起移动。
- 也可以点击图片多选，再点击目标层空白区域放置；键盘可用 Tab 选择目标区域并按 Enter / 空格放置。
- 编辑层级名称、任意标签颜色，添加、删除、上下移动层级。删除层级会将图片退回待排序区。
- 默认每层每行 1–20 张图片，每层可独立覆盖列数；超出后自动换行。
- 统一正方形 (1:1)、竖版 (2:3)、横版 (3:2)、宽屏 (16:9)。支持裁剪填充、完整显示；双击图片或单选后点“调整裁剪”可调整构图。
- 切换比例始终基于本地工作副本，不会反复裁剪；显示图片名称开关。
- PNG 导出（标准 / 高清），保持层级、排列列数、颜色和裁剪，支持标题和待排序区开关。
- JSON 项目导出 / 导入，包含全部工作图片和设置，可跨设备继续编辑。
- IndexedDB 自动保存，刷新恢复；30 步撤销 / 重做。快捷键 Ctrl / ⌘ + Z，Ctrl / ⌘ + Shift + Z。
- 内置可编辑示例、响应式布局；窄屏画板可横向滚动。

## 运行

在仓库根目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

通过本机 8000 端口访问。建议用 HTTP 服务而不是直接打开文件，以便浏览器正常保存项目并载入示例。

## GitHub Pages

在仓库 **Settings → Pages → Build and deployment** 选择 **Deploy from a branch**，分支 **main**，目录 **/ (root)**。保存并等待部署成功后，默认站点地址是 `https://huaizhouh.github.io/`。`.nojekyll` 用于直接提供静态文件。

## 图片与存档

- 支持浏览器可解码的 JPG、PNG、WebP、GIF、AVIF、BMP；动画取静态画面。不接受 SVG 上传。
- 单张上传上限 25 MB。上传时转换为最长边不超过 1600 像素的 WebP 工作副本（不支持 WebP 编码时浏览器回退 PNG），透明区域保留；不保存原始文件。
- 每项目最多 300 张图片、50 个层级。JSON 导入上限 100 MB，校验图片、引用、颜色、列数和裁剪参数，不接受远程图片 URL 或可执行内容。
- 本地自动保存仅对当前浏览器、当前站点有效，受配额和隐私模式影响。清理站点数据会清除存档，请用 JSON 文件备份。
- 超长 PNG 会自动降低分辨率以控制内存和浏览器画布尺寸；超出安全尺寸会提示增加列数或拆分项目。
- 无分析追踪、图片上传和第三方字体；示例复用仓库内的原创 SVG 风景插画。

## 文件结构

- `index.html`：编辑器、设置面板和对话框
- `style.css`：响应式样式和交互状态
- `app.js`：项目数据、拖拽、上传、裁剪、IndexedDB、导入导出
- `assets/`：图标与示例插画

没有构建产物或需要安装的项目依赖。浏览器验证覆盖上传、排序、分层设置、图片比例、撤销、存档恢复和导出。

## 浏览器验证

在已安装 Playwright 的测试环境中，先启动上面的本地 HTTP 服务，再运行：

```sh
CHROMIUM_PATH=/usr/bin/chromium node tests/editor.cjs
```

如果使用 Playwright 自带的 Chromium，省略 `CHROMIUM_PATH`。`TEST_URL` 可以指定其他测试服务地址。验证使用独立浏览器上下文，不修改真实用户存档；下载文件和截图保存在系统临时目录。测试依赖只用于开发，不影响静态部署。
